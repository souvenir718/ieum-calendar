# 이음어린이집 캘린더

이음어린이집의 월별 당직표를 캘린더 형식으로 확인하는 Next.js 웹앱입니다. 당직은 `오전1`, `오전2`, `오후1`, `오후2`로 구분하며, 현재 데이터는 `2026년_7월_당직표.xlsx`를 기반으로 넣었습니다.

## 로컬 실행

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 당직표 규칙

- 당직 슬롯은 `오전1`, `오전2`, `오후1`, `오후2` 네 가지입니다. 슬롯 시간·조기퇴근 규칙은 발효일 이력(`lib/duty-rules.js`의 `DUTY_RULE_HISTORY`)으로 관리하며, 규칙 적용 기준은 **당직을 선 날짜**입니다. 과거 월은 그 시점 규칙 그대로 계산·인쇄됩니다.
  - `오전1`: 7:30 ~ 16:30
  - `오전2`: 8:00 ~ 17:00
  - (**2026-11-01부터**) 교사회의 일정(제목에 "교사회의")이 있는 날의 `오전1`·`오전2`는 당일 대신 다음 근무일에 조기퇴근합니다(당직표 PDF 조기퇴근표에 반영).
  - `오후1`: 9:00 ~ 18:30, 다음날 30분 일찍 퇴근 (**2026-10-01 ~ 10-31 한 달만** 9:00 ~ 19:00 + 1시간 시간 외 수당, **2026-11-01 원복**)
  - `오후2`: 9:30 ~ 19:30, 1시간 시간 외 수당 지급
- 2026년 7월 기준 `2026-07-01`에는 당직을 배정하지 않습니다.
- 당직 근무일은 `2026-07-02`부터 시작하며, 주말과 `2026-07-17` 제헌절을 제외한 21일입니다.
- 하루에는 서로 다른 선생님 4명이 각 슬롯에 1명씩 배정됩니다.
- 전체 배정은 84건이며, 인원별 총 횟수는 12회로 맞춥니다.
- 각 슬롯별 배정 횟수도 선생님별로 3회씩 맞춥니다.
- 같은 반을 맡는 선생님은 같은 날 오전 당직 묶음(`오전1`, `오전2`)이나 오후 당직 묶음(`오후1`, `오후2`)에 함께 배정하지 않습니다.
  - 포근반: 이혜빈, 정지혜, 홍여진
  - 다솜반: 김민경, 최옥희
  - 도담반: 어영경
  - 라온반: 봉은영
- `오후2`를 맡은 선생님은 다음 근무일의 `오전1` 또는 `오전2`에 배정하지 않습니다.
- (**2026-09-30까지, 2026-11-01부터**) `오후1`을 맡은 선생님은 다음 근무일에 0.5 조기퇴근을 하므로, 다음 근무일의 `오후1` 또는 `오후2`에 배정하지 않습니다.
  - 다음 근무일은 주말과 공휴일을 건너뛴 다음 당직일 기준입니다.
  - 가능한 한 오전 당직(`오전1`, `오전2`)도 맡지 않도록 합니다. 즉 다음 근무일에는 당직을 서지 않는 것을 우선합니다. 다른 규칙과 충돌해 불가피한 경우에만 예외로 허용합니다.
- (**2026-10-01 ~ 10-31**) `오후1`에 조기퇴근이 없어져 위 다음 근무일 제약은 해제됩니다. 다만 19시 퇴근 다음날 연속 당직은 가능한 한 지양합니다. `scripts/check-rule.mjs`가 위반이 아닌 `[지양]` 안내로 표시합니다.
- 요일별 체감 균등성을 위해 각 선생님은 월~금 각 요일에 최소 2회, 최대 3회만 배정합니다.
- 같은 선생님이 같은 요일에 같은 슬롯을 반복해서 맡지 않도록 합니다.
- 같은 선생님이 연속된 근무일에 같은 슬롯을 연달아 맡지 않도록 합니다. (예: 어제 `오전1`이면 다음 근무일 `오전1` 금지)
- 완전히 동일한 하루 배정 패턴은 반복하지 않습니다.
- `npm run verify`는 DB 연결 없이 월별 당직 조회, 전월 오후1의 월초 조기퇴근 이월(연휴·연도 경계 포함), 발효일 경계에서의 규칙 전환, 날짜 계산, 일정·당직 입력 형식 검증을 검사합니다. 실제 DB 배정의 균등성이나 반 겹침 검사는 포함하지 않습니다.

## Vercel 배포

```bash
npx vercel@latest
```

운영 배포는 다음 명령을 사용합니다.

```bash
npx vercel@latest --prod
```

이 프로젝트는 외부 런타임 의존성이 없는 정적 사이트라서 Vercel에서 별도 설정 없이 배포할 수 있습니다.
Next.js 프로젝트이므로 Vercel에서는 빌드 명령 `npm run build`를 실행한 뒤 Next 출력물을 자동으로 배포합니다.

## 사용 (월 이동)

- 상단 화살표로 이전/다음 달 이동. 인접 월은 미리 prefetch되어 즉시 전환된다.
- **모바일**: 캘린더 영역을 좌/우로 스와이프해도 월이 이동한다(왼쪽 → 다음 달, 오른쪽 → 이전 달). 세로 스크롤·핀치 줌·모달 열림 중에는 스와이프가 동작하지 않는다.

- 상단 **일정 추가**의 기본 날짜는 한국 시간 기준 오늘입니다. 날짜 칸을 누르면 해당 날짜로 추가합니다.
- 인쇄용 조기퇴근 내역은 이전 오후1 배정과 공휴일을 함께 조회해 월초 이월을 반영합니다.

## 구현 완료

- **Supabase(Postgres + RLS)** 기반 데이터 저장. 공개 읽기(anon), 쓰기는 서버 service_role.
- 이전/다음 달 이동 (화살표 + 모바일 스와이프).
- 당직 추가·수정·삭제 — PIN 잠금 해제 후 편집(`오전1/오전2/오후1`, 오후2는 정책에 따라 재개/폐지).
- 일정(행사·연차·오전반차·오후반차·생일·중요·기타) 추가·수정·삭제.
- PIN 기반 편집 세션(당직 편집 보호), PWA 설치, 당직표/일정표 PDF 인쇄, 통계 페이지.

## 다음 단계 (미구현)

- **Supabase Realtime** — 여러 사용자가 보는 화면에 변경 사항 실시간 반영(현재는 ISM `revalidate=60`로 최대 60초 지연).
- **일정 API 인증** — 당직은 PIN 세션으로 보호되지만 일정 CRUD(`/api/events*`)는 현재 무인증. 인증/권한 추가 검토.
- **사용자 계정/역할(`profiles`)** — 공유 PIN 대신 개인 계정 기반 권한 관리.
- 당직 자동 배정 생성기(규칙 기반), 통계 페이지 확장.
