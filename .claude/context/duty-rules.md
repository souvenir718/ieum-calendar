# 당직 슬롯 도메인 규칙

당직표/조기퇴근 계산이나 배정 로직을 건드릴 때 참조.

- 슬롯: `오전1`, `오전2`, `오후1`, `오후2`. 순서는 `lib/calendar.js`의 `SLOT_ORDER`.
- 편집 대상 슬롯은 `lib/duties.js`의 `EDITABLE_SLOTS = ["오전1","오전2","오후1","오후2"]`. **`오후2`는 2026-07-20 폐지 후 재개**되어 다시 편집·배정 가능.
  - 2026-07-20 ~ 07-26 구간에는 오후2 행이 없다(폐지 기간). 전체 규칙·이력은 `docs/당직규칙.md` 참고.
- **슬롯 시간·조기퇴근·시간외수당 규칙은 `lib/duty-rules.js`의 `DUTY_RULE_HISTORY`에 발효일(`from`)별 이력으로 있다.** 규칙이 바뀌면 값을 고치지 말고 새 `{ from, slots }` 항목을 덧붙일 것(각 항목은 직전 규칙에 대한 부분 덮어쓰기). 되돌릴 때도 revert가 아니라 항목 추가.
  - 규칙은 **당직을 선 날짜** 기준으로 고른다 → 2026-09-30 오후1의 0.5 조기퇴근은 발생일이 10-01이어도 유지된다.
  - 소비처: `deriveEarlyLeave`(파생), `dutySlotsFor`(범례·당직 모달), `dutyHoursAt`(인쇄 당직시간), `check-rule.mjs`(제약 판정).
- 조기퇴근 파생(`deriveEarlyLeave`): 오전1→당일 1.5h, 오전2→당일 1.0h, 오후1→**다음 근무일**(주말·공휴일 제외) 0.5h (**2026-09-30까지**. 2026-10-01부터 오후1은 조기퇴근 없이 1시간 시간외수당).
- 2026-10-01부터 "오후1 담당자는 다음 근무일에 당직 금지" 제약은 해제됐다(연속 근무는 지양 → `check-rule.mjs`가 `[지양]`으로 안내).
- 배정 제약(반 겹침, 연속일 같은 슬롯 금지, 요일 균등 등)의 전체 명세는 `README.md`와 `docs/당직규칙.md`에 있고, `scripts/check-rule.mjs`로 점검한다.
