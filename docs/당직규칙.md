# 당직 규칙

## 규칙은 발효일 기준으로 관리한다

슬롯 시간·조기퇴근·시간외수당은 `lib/duty-rules.js`의 `DUTY_RULE_HISTORY`에 **발효일(`from`)이
붙은 이력**으로 들어 있다. 규칙이 바뀌면 기존 값을 고치는 게 아니라 새 발효일 항목을 덧붙인다.

- 과거 월을 조회·인쇄하면 그 시점 규칙으로 계산되므로, 공람이 끝난 당직표가 소급 변경되지 않는다.
- 규칙 적용 기준은 **당직을 선 날짜**다. 2026-09-30 오후1의 0.5 조기퇴근은 발생일이 10-01이어도
  9월 규칙을 따라 그대로 남는다.
- 되돌릴 때도 코드를 revert하지 않고 `{ from: "...", slots: { ...옛 규칙 } }`을 추가한다.

## 현재 상태

**2026-11-01 ~ 교사회의 날 오전 당직 조기퇴근 이동.** 일정 제목에 "교사회의"(띄어쓰기 무관)가
있는 날의 오전1·오전2 담당자는 회의 때문에 당일 조기퇴근 대신 **다음 근무일**에 같은 시간(1.5/1.0)
조기퇴근한다. 당직표 PDF의 조기퇴근표에 반영된다. 전월 마지막 근무일이 교사회의면 다음 달 첫
근무일로 이월된다.

**2026-11-01 ~ 오후1 원복.** 오후1이 다시 **9:00–18:30 + 다음 근무일 0.5시간 조기퇴근**이다.
"오후1 담당자는 다음 근무일의 오후1/오후2에 배정하지 않는다" 제약도 다시 적용된다
(`scripts/plan-duties.mjs`가 하드 제약으로 지키고 `scripts/check-rule.mjs`가 위반으로 잡는다).
규칙은 당직을 선 날짜 기준이므로 2026-10-30(금) 오후1은 10월 규칙(시간외수당)이고
11-02 조기퇴근으로 이월되지 않는다.

**2026-10-01 ~ 10-31 오후1 근무시간 변경(한 달 시행).** 오후1이 9:00–18:30 + 다음날 0.5시간 조기퇴근에서
**9:00–19:00 + 1시간 시간외수당**으로 바뀌었다. 조기퇴근이 사라지므로 "오후1 담당자는 다음
근무일의 오후1/오후2에 배정하지 않는다"는 제약도 함께 해제된다(연속 근무는 지양 —
`scripts/check-rule.mjs`가 `[지양]` 안내로 알려준다).
11월부터 원복되어 `DUTY_RULE_HISTORY`에 `from: "2026-11-01"` 항목이 추가됐다.

**2026-07-27 ~ 오후2 당직 재개.** 오후2 슬롯을 다시 편집·배정할 수 있다
(`lib/duties.js`의 `EDITABLE_SLOTS`에 `"오후2"` 포함).
2026-07-20 ~ 07-26 구간은 폐지 기간이라 `duties`에 오후2 행이 없다 — 필요하면 아래
"2026-07-20 오후2 폐지 재배치 이력"의 백업으로 되돌릴 수 있다.

## 조기퇴근 파생 규칙

당직 배정에서 자동으로 계산됨 (`lib/calendar.js`의 `deriveEarlyLeave` + `lib/duty-rules.js`의 규칙):

- 오전1 당직 → **당일** 1.5시간 조기퇴근 (2026-11-01부터 교사회의 날이면 **다음 근무일**)
- 오전2 당직 → **당일** 1.0시간 조기퇴근 (2026-11-01부터 교사회의 날이면 **다음 근무일**)
- 오후1 당직 → **다음 근무일**(주말·공휴일 제외) 0.5시간 조기퇴근 /
  2026-10-01 ~ 10-31만 조기퇴근 없음, 대신 1시간 시간외수당
- 오후2 당직 → 조기퇴근 없음, 대신 1시간 시간외수당

조기퇴근 시간 → 실제 퇴근시각: 0.5시간→17:30, 1시간→17:00, 1.5시간→16:30, 2시간→16:00

## 휴일/주말 처리

- 일요일은 당직표에서 제외
- 토요일은 당직 배정이 있어도 표시하지 않음(대시 처리)
- 공휴일은 별도 표기

## 배정(로테이션) 방식

코드에 자동 배정/로테이션 알고리즘은 없다. `duties` 테이블에 수동으로 입력된 데이터를
그대로 화면·인쇄물에 반영할 뿐이다.
