# 당직 규칙

## 현재 상태 (2026-07-27 ~)

**오후2 당직 재개.** 오후2 슬롯을 다시 편집·배정할 수 있다
(`lib/duties.js`의 `EDITABLE_SLOTS`에 `"오후2"` 포함).
2026-07-20 ~ 07-26 구간은 폐지 기간이라 `duties`에 오후2 행이 없다 — 필요하면 아래
"2026-07-20 오후2 폐지 재배치 이력"의 백업으로 되돌릴 수 있다.

## 슬롯 정의

| 슬롯 | 근무시간 | 비고 |
|---|---|---|
| 오전1 | 7:30–16:30 | 당일 조기퇴근 1.5시간 |
| 오전2 | 8:00–17:00 | 당일 조기퇴근 1.0시간 |
| 오후1 | 9:00–18:30 | 다음 근무일 0.5시간 일찍 퇴근 |
| 오후2 | 9:30–19:30 | 1시간 시간외수당 지급 |

당직 커버 시간대(실제 당직 업무가 필요한 시간): 오전1(7:30–9:00), 오전2(8:00–9:00),
오후1(16:30–18:30), 오후2(16:30–19:30).

비고: "보육교사 - 1개월 단위 탄력적 근로제" 적용.

## 조기퇴근 파생 규칙

당직 배정에서 자동으로 계산됨 (`lib/calendar.js`의 `deriveEarlyLeave`):

- 오전1 당직 → **당일** 1.5시간 조기퇴근
- 오전2 당직 → **당일** 1.0시간 조기퇴근
- 오후1 당직 → **다음 근무일**(주말·공휴일 제외) 0.5시간 조기퇴근
- 오후2 당직 → 조기퇴근 없음, 대신 1시간 시간외수당

조기퇴근 시간 → 실제 퇴근시각: 0.5시간→17:30, 1시간→17:00, 1.5시간→16:30, 2시간→16:00

## 휴일/주말 처리

- 일요일은 당직표에서 제외
- 토요일은 당직 배정이 있어도 표시하지 않음(대시 처리)
- 공휴일은 별도 표기

## 배정(로테이션) 방식

코드에 자동 배정/로테이션 알고리즘은 없다. `duties` 테이블에 수동으로 입력된 데이터를
그대로 화면·인쇄물에 반영할 뿐이다.

## 2026-07-20 오후2 폐지 재배치 이력

7월 20~31일 구간에서 기존 오후2 배정을 제거하고, 인당 당직 총횟수가 최대한 균등하도록
(월 전체 기준 10~11회, 최대 1회 차이) 오전1/오전2/오후1로 재배치했다.
